# Новые банковские операции #
## Цель проекта ##
Раcширить функционал банковских операций.
## Установка ##
1. Клонируйте [проект] https://github.com/KONSTANTIN0712/Bank_widget/tree/feature/src
2.установите все зависимости
## Использование ##
В проекте есть несколько функции, реализующих разные задачи:
* функция filter_by_state, сортирует операции по статусу
* функция sort_by_date, сортирует данные операций по дате
* функция mask_account_card, скрывает счёт или номер карты
* функция filter_by_state, принимает на вход список словарей и параметр сортировки,
    возвращает новый отсортированный список по параметру 'state
* функция sort_by_date, принимает на вход список словарей и параметр порядка
    сортировки, возвращает новый список, в котором исходные словари отсортированы по дате.
## Тестирование ##
В проекте представлены следующие функции тестов:
* test_get_mask_card_number_space, тесты для функции маскировки номера карты (работа кода с пробелами)
* test_get_mask_card_number_len, тесты для функции маскировки номера карты (длина строки)
* test_get_mask_card_number_empty_line, тесты для функции маскировки номера карты (пустая строка)
* test_get_mask_account_space, тесты для функции маскировки номера счета (работа кода с пробелами)
* test_get_number_account_len, тесты для функции маскировки номера счета (длина строки)
* test_get_number_account_empty_line, тест пустой строки
* test_mask_account_card, тест функции определяющей счет или карта и правильности маскировки
* test_mask_account_card_len, тест определения корректности работы при некорректном количестве символов
* test_mask_account_empty_line, тест корректности работы при пустой строке
* test_get_date, тест корректности работы функции для работы с датой
* test_get_date_empty_line, тест корректности работы функции даты при пустой сроке
* test_filter_by_state, тест с использованием стандартных значений
* test_filter_by_state_no_state, тест функции с отсутствующим значением state
* test_sort_by_date, Тест функции сортировки по дате
* test_sort_date_non_date, тест функции сортировки с отсутствием даты
